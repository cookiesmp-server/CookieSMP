Nasıl katılırım?

Java Edition ile 1 dakikada gir.

  1. Minecraft Java Edition'ı aç, Multiplayer'a gir.
  2. Add Server'a tıkla.
  3. Adrese cookiesmp.mangoohost.live yaz.
  4. Done'a bas ve gir. Afiyet olsun!
